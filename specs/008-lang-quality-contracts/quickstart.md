# Quickstart: Language Quality Contracts

**Branch**: `008-lang-quality-contracts`

## What this feature does

Adds per-language caption quality validation for 7 launch languages. After a caption is generated by Gemini, the system runs language-specific checks (word count, Arabic script ratio, dialect markers, grammar heuristics) and triggers a repair prompt if any check fails. Results are persisted as `captionQuality` on the generation's Firestore document.

## Files to modify

| File | Action | What changes |
|------|--------|-------------|
| `functions/src/captionValidator.ts` | Modify | Add `validateLanguageQuality()`, `CaptionQualityResult`, `CaptionQualityCheck`, `LanguageQualityInput` types, and per-language check functions |
| `functions/src/generators.ts` | Modify | Call `validateLanguageQuality()` in the caption retry loop; persist `captionQuality` to Firestore |
| `functions/src/dialectMarkers.ts` | Create | Static dialect marker exclusion lists for Egyptian and Gulf Arabic |
| `functions/src/languageQuality.test.ts` | Create | 21+ unit test cases (3 per language × 7 languages) |

## Development workflow

```bash
# 1. Run existing tests to confirm baseline
cd functions && npm test

# 2. Make changes to captionValidator.ts and generators.ts

# 3. Build and run language quality tests
npm run build && node lib/languageQuality.test.js

# 4. Run all tests to confirm no regressions
npm test
```

## Key design decisions

1. **New function, not modified existing**: `validateLanguageQuality()` is separate from `validateCaption()` — both run in the caption retry loop
2. **Dialect markers in separate file**: `dialectMarkers.ts` keeps marker lists maintainable
3. **Absence-based dialect checking**: Check for wrong-dialect markers, not correct-dialect markers
4. **Word count = whitespace split**: `text.trim().split(/\s+/).length`
5. **captionQuality is a sibling of resolutionTrace**: Top-level field on `generations/{genId}`, not nested inside `ResolutionTrace`

## Test structure

Each language has 3 minimum test cases:
- **Pass case**: Valid caption that passes all checks
- **Word count fail**: Headline exceeding 8 words
- **Language-specific fail**: Hanging conjunction (Fusha), wrong dialect markers (Egyptian/Gulf), Arabic ratio below 70% (lighter dialects), missing CTA (English)
